Privacy, plainly.

Updated October 17, 2026.

Your project brief stays with you.

The project planner creates a text file in your browser. It does not submit your entries to Hankins, store them in a database, or send them to an AI service. Reloading the page may clear what you entered. Keep the downloaded file if you want to use it later.

No tracking scripts.

This website uses no analytics scripts, advertising trackers, cookies, or local storage. Fonts and page assets are served with the site.

Hosting and external links.

The site is published using GitHub Pages. The hosting provider may process technical request information, including your IP address, under its own privacy statement. Following a GitHub link takes you to a separate service with its own policies.

Keep sensitive details out.

Do not put credentials, sensitive security findings, or confidential system information into public GitHub discussions. A suitable communication channel and data handling arrangements should be agreed before sharing project details.
